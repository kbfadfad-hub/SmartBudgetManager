# SmartBudgetManager
A project for managing Budget.
README
What is it?
SmartBudget Manager is an Excel workbook for recording monthly income and expenses and monitoring a budget.
Worksheets
Dashboard: summary totals, category budget table, remaining budget, status, and expense pie chart.
Transactions: transaction entry table with Date, Description, Type, Category, Income, Expense, Notes, and automatic Month.
Categories: predefined categories and editable monthly budget amounts.
Requirements
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
Quick start
1. Open SmartBudget_Manager.xlsx.
2. Open Transactions and enter a new transaction in the first empty row (rows 4–50 are prepared for entries).
3. Enter a date and description, select Type and Category, and enter the amount in Income or Expense.
4. Do not overwrite the Month formula.
5. In Categories, review or change the monthly budgets.
6. Open Dashboard to review totals, balance, status, and the category chart.
7. Save with Ctrl+S.
